## 🚀 Cara Menjalankan Secara Lokal

1. **Clone repository**:
   ```bash
   git clone https://github.com/arsyadal/raisya-salon.git
   cd raisya-salon
   ```

2. **Jalankan preview server lokal**:
   ```bash
   node local-server.js
   ```

3. **Buka di browser**:
   Akses `http://localhost:3000` atau buka berkas `index.html` langsung.
